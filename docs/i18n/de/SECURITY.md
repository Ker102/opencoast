# Sicherheitsmeldungen

Melde vermutete Sicherheitsprobleme über [GitHubs private Schwachstellenmeldung](https://github.com/Ker102/opencoast/security/advisories/new). Füge keine echten Eingangslinks von Beitragenden, Belegdateien oder Zugangsdaten in ein öffentliches Issue ein.

Wir prüfen die Meldung vertraulich, reproduzieren das Problem und koordinieren eine Behebung vor der öffentlichen Offenlegung. Für gewöhnliche Fehler oder Funktionswünsche nutze den öffentlichen Issue-Tracker.
