# Relatos de segurança

Relate suspeitas de problemas de segurança pelo [canal privado de vulnerabilidades do GitHub](https://github.com/Ker102/opencoast/security/advisories/new). Não inclua links reais de acompanhamento de colaboradores, arquivos de evidência ou credenciais em uma issue pública.

Revisaremos o relato em privado, reproduziremos o problema e coordenaremos uma correção antes da divulgação pública. Para bugs comuns ou solicitações de funcionalidades, use o rastreador público de issues.
