# Informes de seguridad

Comunica los posibles problemas de seguridad mediante los [informes privados de vulnerabilidades de GitHub](https://github.com/Ker102/opencoast/security/advisories/new). No incluyas enlaces reales de seguimiento de colaboradores, archivos de evidencia ni credenciales en un issue público.

Revisaremos el informe en privado, lo reproduciremos y coordinaremos una solución antes de divulgarlo públicamente. Para errores ordinarios o solicitudes de funcionalidades, utiliza el seguimiento público de issues.
