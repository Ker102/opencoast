# Signalement de sécurité

Signalez les problèmes de sécurité présumés via le [signalement privé de vulnérabilités GitHub](https://github.com/Ker102/opencoast/security/advisories/new). N’incluez pas de vrais liens de reçu de contributeurs, fichiers de preuve ou identifiants dans une issue publique.

Nous examinerons le rapport en privé, reproduirons le problème et coordonnerons un correctif avant sa divulgation publique. Pour les bogues ordinaires ou demandes de fonctionnalités, utilisez le suivi public des issues.
